# Cross Puzzle
Крайне примитивная головоломка на Pygame, идеей обязана багу при разработке игры "Жизнь". 

Правила: 
- Нажатие любой кнопки мыши изменяет цвет клеток креста с центром в нажатой на противоположный

Уровни генерируются автоматически с помощью имитации случайных нажатий. Количество нажатий на каждом уровне соответствует номеру уровня, то есть каждый уровень разрешим за число нажатий, не превышающее его номер.

Дополнительные опции:
- C - очистить уровень
- R - перегенерировать уровень (номер и сложность сохраняются)
- S - перезапускает игру
